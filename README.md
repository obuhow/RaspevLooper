# DAW

Отдельный проект для Ubuntu/Linux desktop: live-looper с функциями DAW.

## Зафиксированные границы MVP

- 2–4 аудиодорожки;
- MIDI;
- live-looping;
- студийное написание музыки как основной сценарий;
- AI-рекомендации выполняются гибридно: базовые функции локально, тяжёлые операции через API;
- AI только предлагает варианты, пользователь подтверждает применение;
- рекомендации включают выравнивание лупов, MIDI-материал, автоматизацию эффектов и подбор тембра инструмента под записанный голос.

Проект не является частью `wolf`.

## Дополнительные решения

- GitHub-репозиторий — приватный;
- в MVP нет поддержки внешних VST/LV2/CLAP-плагинов;
- лупы фиксированной длины в тактах, с темпом и музыкальной сеткой;
- AI предлагает параметры и настройки синтезатора, пользователь подтверждает применение;
- AI не изменяет звук автоматически и не генерирует обработанный аудиофайл в MVP.
- MIDI-инструменты MVP: простой встроенный синтезатор и базовый сэмплер;
- начало и конец лупа квантуются по границам тактов, исходная запись сохраняется;
- проект неразрушающий: аудио и MIDI хранятся отдельно, доступны экспорт WAV и stems;
- характеристики голоса извлекаются локально, в API отправляются только необходимые признаки, от API возвращаются параметры синтезатора.
- PipeWire используется как основной аудиобэкенд с совместимостью JACK;
- looping-ядро дополняется базовой линейной временной шкалой;
- MIDI-генерация ограничена редактируемыми мотивами на 1–8 тактов с учётом тональности, аккордов и темпа;
- при недоступном API аудио и базовые функции продолжают работать, AI-рекомендации временно недоступны;
- запись MVP включает вход, мониторинг, метроном, count-in и overdub.
- BPM задаётся заранее, поддерживается tap tempo, первый луп не меняет глобальный темп;
- overdub сохраняется отдельным неразрушающим слоем с возможностью отключения и удаления;
- базовая временная шкала поддерживает копирование, перемещение, обрезку и удаление лупов без полноценного аудиомонтажа;
- интерфейс — нативное desktop-приложение с одним главным окном;
- AI-рекомендации проходят предпрослушивание, подтверждение и применение с возможностью Undo.
- MVP ограничивает одновременную работу четырьмя аудиодорожками;
- основной формат аудио — WAV 48 кГц, 24-bit, с поддержкой моно и стерео;
- в MVP используется размер 4/4 и сетка 1/4, 1/8, 1/16 с триолями;
- AI API провайдер-агностичный: endpoint и ключ задаются в настройках;
- проект поддерживает автосохранение, Undo/Redo и восстановление последней сессии после сбоя.
- live-управление включает keyboard shortcuts и MIDI Learn для транспорта, записи и лупов;
- экспорт включает стереомикс, отдельные stems и MIDI-файлы;
- API-ключ хранится в системном хранилище секретов и не попадает в файл проекта;
- встроенные инструменты MVP: один субтрактивный синтезатор с oscillator/filter/envelope/LFO и WAV-сэмплер;
- проект — самодостаточная папка с аудио, MIDI и настройками, переносимая на другой компьютер.

## Дополнительные продуктовые решения

- максимум четыре MIDI-дорожки;
- на каждой дорожке размещается последовательность экземпляров лупа без scene matrix;
- AI-поток: выбор вокальной и инструментальной дорожек → Suggest → предпрослушивание вариантов → применение;
- новый проект по умолчанию: 120 BPM, размер 4/4 и одна тактовая count-in.
